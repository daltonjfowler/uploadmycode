Your libraries

Libraries you added yourself. They stay in this browser and are sent with every compile. Add a library's .zip (the green Code → Download ZIP button on GitHub), or its .h and .cpp files.

    How to code

    1. Write your sketch. Pick a sketch from the Sketch list, or File → New sketch. It saves itself in this browser as you type. File → Download .ino file keeps a copy.
    2. Compile. Press Compile (or Ctrl+Enter). The first time, type the class phrase from the board. Errors show in Output: click one to jump to that line.
    3. Plug in the Uno with its USB cable.
    4. Upload. Press Upload. The first time, pick the board in the window that opens and press Connect.
    5. Watch it run. Open the Serial monitor at the bottom to see what your sketch prints. Set the baud rate to match Serial.begin(). 📈 Plot draws the numbers as a graph.

    Handy keys

    Undo / redoCtrl+Z · Ctrl+Y
    Tidy the spacingAuto indent (Undo puts it back)
    Add a libraryPick it from the library list. It adds the #include line. Not in the list? Add your own library takes its .zip.

    Upload trouble

    • Board not in the list? Try another USB cable or port. Some cables only charge.
    • Close any other tab that is using the board.
    • Upload is greyed out? Compile first. It only uploads what is on screen right now.
