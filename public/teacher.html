Boards

Arduino UNO is always on. Switch ESP32 on and students get a board picker next to Compile. The ESP32 compiler is a bigger server that only wakes while ESP32 is on, so switch it off when the class is done. A change can take up to a minute to reach every student.

Reading the board settings...

ESP32 Wi-Fi safety failsafe

On by default. It refuses ESP32 sketches that use Wi-Fi or Bluetooth attack tools: deauth (knocking people off a network), beacon spam, packet sniffing, and firmware like ESP32 Marauder. It checks the sketch, the student's own libraries, and the finished program. It only covers this site: it cannot stop a student flashing such firmware with other software. Switch it off only for a supervised lesson on your own test network; it turns itself back on when the time runs out.

Project this page, or just write the phrase on the board. Pop out opens a small window holding nothing but the phrase; drag that one onto the projector screen and click it to fill the screen. After setting it, open the editor and click Compile once. That wakes the compiler so the first student does not wait for a cold start.
