Privacy and legal

uploadmycode · last updated 2026-09-26

What this is

uploadmycode is an independent classroom project made by Dalton Fowler, a teacher, for his school district's classes. It is not a commercial product and has no accounts, ads or payments.

Safety

uploadmycode is not a safety system. It compiles the code you write and uploads it to a microcontroller board plugged into this computer. The limits it applies reduce mistakes; they do not make a project safe.

  • A trained adult checks the wiring and supervises the class whenever boards are plugged in.
  • Wiring, batteries, motors and mains power are the teacher's call. Ask before you connect any of them.
  • Unplug the board from the computer before you change any wiring.
  • The site checks that a program fits on the board and was built from the code on screen. It cannot tell whether a program is safe for what is wired to the board.

The software is provided "as is", without warranty of any kind, as its open-source licence says.

Privacy

  • Your code leaves this computer only when you press Compile or Auto indent. The site never asks for your name.
  • Compile sends your code to the compile server. The server writes it to a working file, builds it, and sends back the program or the error messages. That working file and the built program are deleted as soon as the compile finishes. Your code is not saved anywhere else and is not written to the server's logs.
  • Auto indent sends your code to the same server, which tidies it in memory and sends it back without writing it to disk. If tidying fails, the first part of the tool's error message goes into the server log, and that message can quote a line of your code.
  • The class phrase the teacher sets is kept on the server, with the time it ends, until it runs out (12 hours at most) or the teacher ends it. Nothing else about the class is kept there.
  • To share the compiler fairly, the server counts each browser's compiles for one minute, using a random id the browser made (or the network address if there is no id). Those counts are held in memory only and never saved.
  • The class phrase you type is kept for the open tab only and is forgotten when the tab closes. On the teacher page, the teacher key is kept in that browser only if the teacher presses Remember on this machine.
  • Your sketches are saved in this browser only, never on the server. Use Download .ino file to keep a copy somewhere else.
  • No accounts, no cookies, no ads, no tracking. Cloudflare adds a Web Analytics script to the site; this site's security settings block it, so it collects nothing.
  • The site runs on Cloudflare. Like any web host, Cloudflare keeps short request logs (for example the page asked for, the time, the browser and the network address) for up to 7 days, to keep the site running. They are not used for anything else.
  • Your browser may keep your own settings and work (for example your theme, and your saved sketches and which one was open, your editor and serial monitor settings, the panel sizes, and the random id used to share the compiler fairly) on this device only. Clearing site data removes them.
