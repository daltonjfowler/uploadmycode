uploadmycode: third-party licences
==============================================================================

This file lists the other people's code that reaches your computer when you
use this site, and the licence each one is under. There are two kinds:

  1. Code that runs in your browser: the editor.
  2. Code inside your compiled program: the parts of the board core and of the
     libraries that the compiler builds into the hex file sent to your board.

A third list, the compiler toolchain, runs on the server only and is never
sent to you. It is at the end, for completeness.

This site's own code is MIT licensed:
https://github.com/daltonjfowler/uploadmycode (see LICENSE there).
The full credits, with how each fact was checked, are in CREDITS.md in the
same repository.

==============================================================================
PART 2. CODE INSIDE YOUR COMPILED PROGRAM
==============================================================================

When you press Compile, the server builds your sketch together with the parts
of the pieces below that your sketch uses, and sends the result (a hex file)
to your browser, which writes it onto the board. That code keeps its own
licence. Your own sketch is yours.

Board core and libraries under the LGPL
----------------------------------------

  Arduino AVR Boards core (arduino:avr) 1.8.8   LGPL-2.1-or-later
    The setup/loop, pinMode, digitalWrite, Serial ... code every sketch uses.
    Source: https://github.com/arduino/ArduinoCore-avr

  Servo 1.3.0                          LGPL-2.1
    Source: https://github.com/arduino-libraries/Servo

  LiquidCrystal 1.0.7                  LGPL-2.1-or-later
    Source: https://github.com/arduino-libraries/LiquidCrystal

  Stepper 1.1.3                        LGPL-2.1-or-later
    Source: https://github.com/arduino-libraries/Stepper

  Licence text: https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html

  The LGPL lets you change these libraries and rebuild your program with the
  changed version. You have what that needs: your own sketch, and the library
  source at the links above. The repository README explains how to compile
  with the same pinned versions on your own computer.

Libraries under the MPL
-----------------------

  Arduino SensorKit 1.4.0              MPL-2.0
    Source: https://github.com/arduino-libraries/Arduino_SensorKit
    Licence text: https://www.mozilla.org/en-US/MPL/2.0/
    (The installed release ships no licence file; the licence is the one
    stated in the project's repository.)

  SensorKit carries three other libraries inside its own source tree. They
  keep their own licences, printed in full further down:
    U8g2 2.34.22 (OLED display)                 BSD-2-Clause, fonts under their own terms
    Grove Barometer Sensor BMP280 1.0.1         MIT
    Grove Temperature And Humidity Sensor 2.0.1 MIT

Library with NO STATED LICENCE
------------------------------

  LiquidCrystal I2C 1.1.2              no licence stated
    By Frank de Brabander, maintained by Marco Schwartz.
    Home:   https://github.com/marcoschwartz/LiquidCrystal_I2C
    Source of the release served: https://github.com/johnrickman/LiquidCrystal_I2C
    The release ships no licence file and the library index gives no licence.
    Because no licence is stated, the terms for using and sharing it are
    unclear. It is offered because classroom I2C LCD kits need it, and the
    site owner is reviewing it. Its code only lands in your program if your
    sketch includes LiquidCrystal_I2C.h.
